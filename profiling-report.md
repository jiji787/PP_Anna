# Отчёт о профилировании (День 21)

## Цель
Проверить производительность запроса "Сумма покупок по клиентам" в консольном приложении и при необходимости оптимизировать.

## Методика
- Использован `System.Diagnostics.Stopwatch` для замера времени выполнения.
- Запрос выполняется с JOIN между таблицами `users`, `orders`, `order_items` и агрегацией `SUM`.

## Результаты замеров
| Попытка | Время (мс) |
|---------|------------|
| 1       | 41         |
| 2       | 11         |
| 3       | 118        |
| 4       | 115        |

Среднее время выполнения: ~71 мс.

## Оптимизация
Индексы уже были добавлены ранее (день 16–17):
```sql
CREATE INDEX idx_orders_user_id ON orders(user_id);
CREATE INDEX idx_order_items_order_id ON order_items(order_id);

```

# Вывод:
## Запрос выполняется быстро (менее 120 мс), дополнительная оптимизация не требуется. Индексы эффективно ускоряют JOIN-запросы.
